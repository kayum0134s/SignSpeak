## 🚀 Quick Reference

- **Frontend Tech**: Vanilla HTML5, Modern CSS3 (Glassmorphism), ES6+ Native Modules
- **Backend Service**: Python FastAPI Microservice (`backend/app/main.py`) with full CORS & OpenAPI docs
- **Standalone Static Host**: Python standard library server via `python scripts/server.py`
- **Supported Dialects**: American Sign Language (ASL) & Indian Sign Language (ISL)
- **Zero Heavy ML Bloat**: Deterministic greedy tokenization, sub-50ms latency, 100% offline fallback capability.
